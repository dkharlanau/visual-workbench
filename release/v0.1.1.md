# Visual Workbench v0.1.1

This patch release completes the public cross-project documentation for the domain contracts that Visual Workbench may project.

## Changed

- Added explicit links and semantic-ownership boundaries for Process as Code, Interface as Code, Reconciliation as Code, and Cutover Graph.
- Clarified that a visual projection preserves upstream ownership and does not claim a native adapter, control execution, or evidence validation where those capabilities are not implemented and tested.

## Compatibility

The metadata language, CLI behavior, rendering fixtures, and golden SVG digest are unchanged from v0.1.0. Run the [golden quickstart](../docs/GOLDEN_QUICKSTART.md) to verify the released tag.

## Distribution

The GitHub Release attaches the reproducible npm package tarball, deterministic source archive, and SHA-256 checksums. The package remains a source distribution and is not published to the npm registry.
