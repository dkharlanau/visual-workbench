# Visual Workbench v0.1.0

The first public source release provides a semantic, coordinate-free path from Markdown metadata to validated business-readable SVG and HTML.

## Highlights

- Process, plan, data-flow, relationship, system-flow, and checkpoint-flow methods.
- Named views, semantic ownership lanes, and ordered roadmap stages.
- Deterministic CLI validation, inspection, rendering, and multi-view generation.
- Tested Enterprise Architecture Composer and Project Evidence Graph projections.
- Public generated gallery and machine-readable schema.

## Verify

Run the [golden quickstart](../docs/GOLDEN_QUICKSTART.md). The release attaches a reproducible npm package tarball, deterministic source archive, and checksums built from the tagged commit.

## Compatibility and non-goals

This release does not publish to npm, validate producer-domain claims, provide a general drawing editor, or promise compatibility beyond the tested metadata language and pinned integrations.
