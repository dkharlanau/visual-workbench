# Visualize data flow

Use `data-flow` when data itself matters. Promote important business objects, files, events or messages to `data` nodes instead of hiding everything in edge labels.

Use `system` nodes for applications and platforms, `checkpoint` for validation/reconciliation, `data` edges for movement and `flow` edges for processing progression.

The visual should let a reader answer: where does the data originate, what changes it, where is it checked, and where must it arrive?
